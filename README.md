## Local Development

### 1. Clone the repository

```bash
git clone https://github.com/KevLightfoot/Portfolio.git
cd Portfolio
```

### 2. Run the website

Because the portfolio is a static website, no backend installation is required.

You can open `index.html` directly in a browser or serve the directory locally:

```bash
python -m http.server 8080
```

Visit `http://localhost:8080` in your browser.

## Deployment

The portfolio is hosted using GitHub Pages.

Updates pushed to the configured publishing branch are deployed through GitHub Pages.
